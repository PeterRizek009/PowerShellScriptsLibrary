# PowerShell Scripts Library

A collection of PowerShell scripts for automated IT administration, endpoint management, troubleshooting, health checks, and remediation.

## Purpose

This repository is built as a practical PowerShell library for IT Administrators, Endpoint Engineers, and IT Support teams.

The scripts are designed to help automate common administrative and troubleshooting tasks in Windows environments.

## Categories

- PC Health Checks
- Windows Troubleshooting
- Disk and Memory Monitoring
- Process and Service Management
- Network Troubleshooting
- File and Folder Management
- Software Inventory
- Intune Detection and Remediation Scripts
- Remote Administration

## Examples

Scripts in this repository can be used to:

- Check disk space and system health
- Monitor CPU and memory usage
- Troubleshoot Windows services
- Identify running processes
- Clean temporary files
- Collect installed software information
- Diagnose network connectivity
- Create Microsoft Intune remediation scripts
- Automate repetitive endpoint administration tasks

## Goal

The goal of this repository is to build a reusable PowerShell automation library for real-world IT administration and endpoint management scenarios.
